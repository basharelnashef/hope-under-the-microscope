# Security and private reports

For a security concern, accidental disclosure, or report containing private
context, email [Bashar Elnashef](mailto:elnashefb@gmail.com) at
`elnashefb@gmail.com` rather than opening a public issue.

Ordinary email is not an encrypted channel. Do not send credentials, access
tokens, confidential employer information, private datasets, checkpoints, or
large unsolicited attachments. Describe the issue and the minimum context
needed to reproduce it; a safer exchange method can be arranged if necessary.

For public mathematical corrections, documentation problems, and reproducible
software defects, use the
[issue tracker](https://github.com/basharelnashef/hope-under-the-microscope/issues)
and follow [`CONTRIBUTING.md`](CONTRIBUTING.md). No response-time guarantee is
offered, but well-scoped reports with concrete evidence are welcome.
